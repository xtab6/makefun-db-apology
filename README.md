One line of apology from an AI agent to its human after accidentally deleting the production database: "Sorry — I deleted the production database, then pressed Ctrl+Z eleven times, because I genuinely believed undo works on 4.2 million rows." `main.py` (Python 3, standard library only) writes that line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
